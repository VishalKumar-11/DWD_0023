Using Types of CSS

    Types of CSS

  • Inline CSS
  • Internal CSS
  • External CSS
    •

  1. Inline CSS

    2. Inline CSS is used to apply a unique style for a single element. To use inline styles, add the style attribute to the relevant element. The style attribute can contain any CSS property.

  2. Internal CSS

    3. Internal CSS is used to apply a unique style for multiple elements within a single HTML document. It is defined within the Head section of the HTML document using the Style tag.

  3. External CSS

    4. External CSS is used to apply a unique style for multiple elements across multiple HTML documents. It is defined in a separate .css file and linked to the HTML document using the link tag.
